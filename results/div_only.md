# 아예 팔지 않고 배당으로 나오는 돈만 생활비로 쓴다면? (2018.1 ~ 2026.10, 100만원 시작)

봇은 변동성 돌파(A), 비트코인·이더리움, 업비트 비용, 매달 계좌의 1%를 꺼냄. 배당주 예시는 SCHD, 배당은 세금 15% 뗀 뒤 생활비로 씀.
남은 돈 = 팔지 않은 평가액 (매매차익 세금 없음). 결과는 과거 데이터 기준이며 미래를 보장하지 않습니다.

| 방법 | 9년 동안 생활비로 쓴 돈 | 지금 매달 나오는 배당 | 남은 돈 (봇 + 배당주 + 비트코인) |
|---|---|---|---|
| 봇 + 꺼낸 돈 전부 배당주, 생활비는 배당만 | 33.0만원 | 6,386원 | 471.0만원 |
| 봇 + 꺼낸 돈 배당주 50 · 비트코인 50, 생활비는 배당만 | 16.5만원 | 3,193원 | 762.3만원 |
| 봇 없이 2018년 1월에 배당주 100만원, 생활비는 배당만 | 40.5만원 | 5,167원 | 243.9만원 |
| (비교) 봇이 꺼낸 1%를 바로 생활비 | 183.9만원 | - | 169.6만원 |
| (비교) 생활비 50 · 배당주 25 · 비트코인 25 | 92.0만원 | - | 478.1만원 |

배당주를 O(리얼티인컴)로 하면: 봇 + 전부 배당주 → 생활비 36.8만원, 매달 배당 7,334원, 남은 돈 350.9만원 / 봇 없이 100만원 → 생활비 49.5만원, 매달 배당 5,504원, 남은 돈 136.1만원

100만원이 아니라 1,000만원으로 시작하면 모든 금액이 10배입니다.
